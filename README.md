# 🎓 College Operations Analytics Dashboard

## 📌 Project Overview

This project focuses on analyzing and visualizing student and teacher operational data using Power BI. The dashboard was designed to help educational institutions monitor attendance, fee management, payroll, admissions, and overall operational efficiency through interactive visualizations and KPI tracking.

---

## 🎯 Business Objective

The objective of this project was to create a centralized analytics dashboard for managing student and teacher data efficiently and enabling data-driven decision-making for academic and administrative operations.

---

## 🛠️ Tools & Technologies

* Power BI
* Excel
* Data Cleaning & Transformation
* Data Visualization

---

## 📊 Dashboard Features

### 👨‍🎓 Student Analytics

* Attendance Analysis
* Fee Management Dashboard
* Student Demographics
* Admission & Dropout Analysis
* Academic Performance Tracking
* Parent & Emergency Contact Monitoring

### 👨‍🏫 Teacher Analytics

* Teacher Attendance Monitoring
* Salary & Payroll Analysis
* Hiring & Retention Analysis
* Subject & Workload Analysis
* Department-wise Teacher Distribution

---

## 🔄 Interactive Dashboard Functionality

* Implemented toggle button functionality using bookmarks and slicers in Power BI
* Enabled dynamic switching between Student Dashboard and Teacher Dashboard views using Ctrl + Click interaction
* Designed interactive navigation to display only relevant charts and KPIs based on user selection
* Improved dashboard usability and reporting experience through dynamic visual transitions

---

## 📈 Key Insights

* Identified students with low attendance and pending fees
* Monitored monthly attendance and admission trends
* Analyzed payroll trends and department-wise teacher allocation
* Improved operational visibility through centralized reporting and KPI dashboards
